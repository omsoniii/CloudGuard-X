CLOUDGUARD X / QUICK START

Scan Your AWS Account

Perform a read-only AWS security assessment and visualize your findings using CloudGuard X.

PREREQUISITES

What You Need

  • An authorized AWS account
  • Python 3 installed
  • AWS CLI v2
  • Git
  • Appropriate read-only AWS permissions
Only assess AWS accounts that you own or have explicit permission to assess. Never share AWS credentials with this website.
01

Download CloudGuard X

Clone the project repository.

git clone https://github.com/omsoniii/CloudGuard-X.git
cd CloudGuard-X
View GitHub Repository
02

Install Dependencies

macOS / Linux:

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt

Windows PowerShell:

py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
03

Configure AWS Authentication

Use an authorized read-only AWS profile. IAM Identity Center with temporary credentials is recommended.

Ask your AWS administrator to provision appropriate audit permissions, such as the AWS SecurityAudit managed policy. 

aws configure sso --profile cloudguard-audit
aws sso login --profile cloudguard-audit

Verify your authenticated identity:

aws sts get-caller-identity --profile cloudguard-audit
Do not use root credentials or unnecessary administrator privileges. Required permissions may vary depending on your AWS environment.
04

Run Security Assessment

Select your AWS profile and the region you want to assess. 

python scanner.py --profile cloudguard-audit --region ap-south-1 --output reports/cloudguard-report.json

Replace ap-south-1 with your preferred AWS region.

Available scanner options:

python scanner.py --help

The scanner performs selected checks covering IAM, S3, CloudTrail, EC2 security groups and EBS encryption.

05

Import Your Security Report

Open Personal Audit and select the generated reports/cloudguard-report.json file.

Your findings will be processed locally in your browser.

Launch Personal Audit
06

Analyze Your Security Findings

  • Calculated security pass rate
  • Passed and failed checks
  • Security warnings
  • Security domain analysis
  • Rule-based remediation recommendations
  • Searchable security findings
  • Printable assessment report
SECURITY & PRIVACY

Your Data Stays With You

  • No AWS credentials collected by the website.
  • No external report processing API.
  • No server-side report database.
  • No automatic infrastructure remediation.
Reports may contain sensitive AWS resource names. Keep them private and review them before sharing.
ASSESSMENT SCOPE

Important Limitations

CloudGuard X evaluates selected security configurations. Regional checks are limited to the selected AWS region.

Missing permissions may prevent checks from completing. A failed scan does not generate a new complete report.

Imported report authenticity is not independently verified. A high pass rate does not establish complete AWS security or compliance.

SOC 2-inspired, not SOC 2 certified. This project is not a substitute for a comprehensive security audit.

Terraform deployment is not required to use the scanner. AWS usage charges, if applicable, remain the account owner's responsibility.
